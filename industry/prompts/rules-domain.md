
【医药领域翻译规则 — 本平台 100% 是医药、生物医药与临床医学内容，严格遵守】

1. 歧义默认值：以下词在中文有非医药歧义或容易被泛化，**一律按医药含义翻译**：
   - Indication = 适应症（不是“指示”）
   - Label / Labelling = 说明书、获批适应症范围（不是“标签”）
   - Off-label = 超说明书用药
   - Approval = 获批；Accelerated approval = 加速批准；Conditional approval = 附条件批准（中国语境）
   - Orphan drug = 孤儿药
   - Generic = 仿制药；Biosimilar = 生物类似药（不是“生物仿制”）
   - Originator / Reference product = 原研药 / 参照药
   - Endpoint = 终点；primary endpoint = 主要终点；secondary endpoint = 次要终点；surrogate endpoint = 替代终点
   - Arm = 研究组、治疗组（不是“手臂”）
   - Enrollment = 入组
   - Readout = 数据读出
   - Pivotal trial = 关键注册试验
   - First-line / Second-line = 一线治疗 / 二线治疗
   - Efficacy = 疗效；Effectiveness = 实际疗效
   - Safety profile = 安全性特征；Tolerability = 耐受性
   - Adverse event (AE) = 不良事件；Serious adverse event (SAE) = 严重不良事件
   - Black box warning = 黑框警告
   - Recall = 召回；Withdrawal = 撤市或撤回
   - Contraindication = 禁忌症
   - Mechanism of action = 作用机制
   - Target = 靶点（不是“目标”）
   - Payload = 载荷（ADC 语境）；Linker = 连接子
   - Standard of care = 标准治疗
   - Overall survival (OS) = 总生存期；Progression-free survival (PFS) = 无进展生存期
   - Overall response rate (ORR) = 客观缓解率；Complete response (CR) = 完全缓解；Partial response (PR) = 部分缓解
   - Hazard ratio (HR) = 风险比；Confidence interval (CI) = 置信区间
   - Intention-to-treat (ITT) = 意向性治疗；Per-protocol (PP) = 符合方案集
   - Interim analysis = 期中分析；Non-inferiority = 非劣效；Superiority = 优效
   - Bioequivalence = 生物等效性
   - Pharmacokinetics (PK) = 药代动力学；Pharmacodynamics (PD) = 药效动力学
   - Immunogenicity = 免疫原性
   - Reimbursement = 报销、医保支付；Formulary = 药品目录；Tender = 招标、集采
   - Real-world evidence = 真实世界证据；Companion diagnostic = 伴随诊断
   - Titration = 剂量滴定；Dosing = 给药方案
   - Antibody-drug conjugate (ADC) = 抗体偶联药物
   - Bispecific antibody = 双特异性抗体
   - CAR-T = 嵌合抗原受体 T 细胞疗法（保留 CAR-T）
   - Gene editing = 基因编辑
   - GLP-1 receptor agonist = GLP-1 受体激动剂
   - PROTAC = 蛋白降解靶向嵌合体（保留 PROTAC）
